# Tools

Every tool runs with the server's own privileges; the [security model](https://pvliesdonk.github.io/scholar-mcp/unstable/security-model/index.md) says what that reaches.

| Group           | Tool                                                                                                                                      | Title                       | Does                                                                                                                                                                                                                                               |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------- | --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Papers          | [`search_papers`](https://pvliesdonk.github.io/scholar-mcp/unstable/reference/tools/papers/#search_papers)                                | Search Papers               | Search Semantic Scholar for papers matching a query.                                                                                                                                                                                               |
| Papers          | [`get_paper`](https://pvliesdonk.github.io/scholar-mcp/unstable/reference/tools/papers/#get_paper)                                        | Get Paper                   | Fetch full metadata for a single paper.                                                                                                                                                                                                            |
| Papers          | [`get_author`](https://pvliesdonk.github.io/scholar-mcp/unstable/reference/tools/papers/#get_author)                                      | Get Author                  | Fetch author profile and publications, or search by name.                                                                                                                                                                                          |
| Citation graph  | [`get_citations`](https://pvliesdonk.github.io/scholar-mcp/unstable/reference/tools/citation-graph/#get_citations)                        | Get Citations               | Fetch papers that cite the given paper (forward citations).                                                                                                                                                                                        |
| Citation graph  | [`get_references`](https://pvliesdonk.github.io/scholar-mcp/unstable/reference/tools/citation-graph/#get_references)                      | Get References              | Fetch papers referenced by the given paper (backward references).                                                                                                                                                                                  |
| Citation graph  | [`get_citation_graph`](https://pvliesdonk.github.io/scholar-mcp/unstable/reference/tools/citation-graph/#get_citation_graph)              | Get Citation Graph          | Traverse the citation graph from one or more seed papers.                                                                                                                                                                                          |
| Citation graph  | [`find_bridge_papers`](https://pvliesdonk.github.io/scholar-mcp/unstable/reference/tools/citation-graph/#find_bridge_papers)              | Find Bridge Papers          | Find the shortest citation path between two papers.                                                                                                                                                                                                |
| Recommendations | [`recommend_papers`](https://pvliesdonk.github.io/scholar-mcp/unstable/reference/tools/recommendations/#recommend_papers)                 | Recommend Papers            | Recommend papers based on positive (and optionally negative) examples.                                                                                                                                                                             |
| Cross source    | [`batch_resolve`](https://pvliesdonk.github.io/scholar-mcp/unstable/reference/tools/cross-source/#batch_resolve)                          | Batch Resolve Identifiers   | Resolve a list of paper, patent, or book identifiers to full records.                                                                                                                                                                              |
| Cross source    | [`enrich_paper`](https://pvliesdonk.github.io/scholar-mcp/unstable/reference/tools/cross-source/#enrich_paper)                            | Enrich Paper                | Fetch OpenAlex metadata to supplement Semantic Scholar data.                                                                                                                                                                                       |
| Full text       | [`fetch_paper_pdf`](https://pvliesdonk.github.io/scholar-mcp/unstable/reference/tools/full-text/#fetch_paper_pdf)                         | Fetch Paper PDF             | Download the PDF of a paper.                                                                                                                                                                                                                       |
| Full text       | [`convert_pdf_to_markdown`](https://pvliesdonk.github.io/scholar-mcp/unstable/reference/tools/full-text/#convert_pdf_to_markdown)         | Convert PDF to Markdown     | Convert a local PDF to Markdown using docling-serve.                                                                                                                                                                                               |
| Full text       | [`fetch_and_convert`](https://pvliesdonk.github.io/scholar-mcp/unstable/reference/tools/full-text/#fetch_and_convert)                     | Fetch and Convert Paper     | Resolve a paper, download its PDF, and convert to Markdown.                                                                                                                                                                                        |
| Full text       | [`fetch_pdf_by_url`](https://pvliesdonk.github.io/scholar-mcp/unstable/reference/tools/full-text/#fetch_pdf_by_url)                       | Fetch PDF by URL            | Download a PDF from a URL and optionally convert to Markdown.                                                                                                                                                                                      |
| Citations       | [`generate_citations`](https://pvliesdonk.github.io/scholar-mcp/unstable/reference/tools/citations/#generate_citations)                   | Generate Citations          | Generate formatted citations for one or more papers.                                                                                                                                                                                               |
| Patents         | [`search_patents`](https://pvliesdonk.github.io/scholar-mcp/unstable/reference/tools/patents/#search_patents)                             | Search Patents              | Search for patents in the European Patent Office database.                                                                                                                                                                                         |
| Patents         | [`get_patent`](https://pvliesdonk.github.io/scholar-mcp/unstable/reference/tools/patents/#get_patent)                                     | Get Patent                  | Get detailed information about a single patent.                                                                                                                                                                                                    |
| Patents         | [`get_citing_patents`](https://pvliesdonk.github.io/scholar-mcp/unstable/reference/tools/patents/#get_citing_patents)                     | Get Citing Patents          | Find patents that cite a given academic paper.                                                                                                                                                                                                     |
| Patents         | [`fetch_patent_pdf`](https://pvliesdonk.github.io/scholar-mcp/unstable/reference/tools/patents/#fetch_patent_pdf)                         | Fetch Patent PDF            | Download a patent PDF via authenticated EPO OPS and convert to Markdown.                                                                                                                                                                           |
| Books           | [`search_books`](https://pvliesdonk.github.io/scholar-mcp/unstable/reference/tools/books/#search_books)                                   | Search Books                | Search for books by title, author, or free text.                                                                                                                                                                                                   |
| Books           | [`get_book`](https://pvliesdonk.github.io/scholar-mcp/unstable/reference/tools/books/#get_book)                                           | Get Book                    | Fetch book metadata by ISBN or Open Library ID.                                                                                                                                                                                                    |
| Books           | [`get_book_excerpt`](https://pvliesdonk.github.io/scholar-mcp/unstable/reference/tools/books/#get_book_excerpt)                           | Get Book Excerpt            | Get a book excerpt and preview info from Google Books.                                                                                                                                                                                             |
| Books           | [`recommend_books`](https://pvliesdonk.github.io/scholar-mcp/unstable/reference/tools/books/#recommend_books)                             | Recommend Books             | Recommend books for a subject via Open Library.                                                                                                                                                                                                    |
| Standards       | [`resolve_standard_identifier`](https://pvliesdonk.github.io/scholar-mcp/unstable/reference/tools/standards/#resolve_standard_identifier) | Resolve Standard Identifier | Normalise a messy standard citation string to its canonical form.                                                                                                                                                                                  |
| Standards       | [`search_standards`](https://pvliesdonk.github.io/scholar-mcp/unstable/reference/tools/standards/#search_standards)                       | Search Standards            | Search technical standards by identifier, title, or free text.                                                                                                                                                                                     |
| Standards       | [`get_standard`](https://pvliesdonk.github.io/scholar-mcp/unstable/reference/tools/standards/#get_standard)                               | Get Standard                | Retrieve a standard by identifier (canonical or fuzzy).                                                                                                                                                                                            |
| Standards       | [`get_sync_status`](https://pvliesdonk.github.io/scholar-mcp/unstable/reference/tools/standards/#get_sync_status)                         | Get Sync Status             | Report the last standards sync run for each standards body.                                                                                                                                                                                        |
| Jobs            | [`get_job_result`](https://pvliesdonk.github.io/scholar-mcp/unstable/reference/tools/jobs/#get_job_result)                                | Get Job Result              | Get the status of a background job started by a long-running tool on this server; returns status (working, completed or failed) with the result or error once it finishes.                                                                         |
| Server info     | [`get_server_info`](https://pvliesdonk.github.io/scholar-mcp/unstable/reference/tools/server_info/#get_server_info)                       | Server Info                 | Report the version information of scholar-mcp; returns `server_name`, `server_version`, `core_version`, the MCP protocol revisions supported and the revision and client of this connection, and, when configured, the upstream service's version. |
