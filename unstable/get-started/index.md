# Get started

Each page here takes you from nothing to a first working call with one client. Pick the one you use:

- [Claude Desktop](https://pvliesdonk.github.io/scholar-mcp/unstable/get-started/claude-desktop/index.md): the app starts the server on your machine.
- [Claude Code](https://pvliesdonk.github.io/scholar-mcp/unstable/get-started/claude-code/index.md): the plugin, or a command Claude Code starts for you. The same page connects it to a server that already runs.
- [A remote server](https://pvliesdonk.github.io/scholar-mcp/unstable/get-started/http-client/index.md): someone gave you a URL, and you want claude.ai or another client to use it.
- [Installation](https://pvliesdonk.github.io/scholar-mcp/unstable/get-started/installation/index.md): every way to install the server, and how to check what you installed.

A first setup is the moment to decide what the server may touch. What it can reach, what it changes and who gets in is set out in the [security model](https://pvliesdonk.github.io/scholar-mcp/unstable/security-model/index.md); each tutorial says which of that its setup allows.

Start read-only: search for papers on a topic you know and follow their citations. PDF download and conversion need write mode and a docling-serve, so add them once the basics work.
